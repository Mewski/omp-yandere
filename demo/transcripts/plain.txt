`i <= arr.length` runs one extra iteration, reading `arr[arr.length]`, which is `undefined`. Adding `undefined` to a number gives `NaN`, and every addition after that stays `NaN`. Use `<` so the last index read is `arr.length - 1`.

```js
let sum = 0;
for (let i = 0; i < arr.length; i++) sum += arr[i];
```
