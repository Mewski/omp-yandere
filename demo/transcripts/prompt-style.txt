The `<=` makes the last pass read `arr[arr.length]`, one past the final element, which is `undefined`. `sum + undefined` becomes `NaN`, and every addition after that stays `NaN`. Use `<` so `i` stops at the last valid index~ (◕‿◕)♡

```js
let sum = 0;
for (let i = 0; i < arr.length; i++) sum += arr[i];
```
