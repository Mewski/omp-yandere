`i <= arr.length` runs one step too far, so the last iteration reads `arr[arr.length]`, which is `undefined`. Adding `undefined` to a number gives `NaN`, and `NaN` then spreads through every later addition. Use `<` so the loop stops at the last valid index, `arr.length - 1` (◕‿◕)♡

```js
let sum = 0;
for (let i = 0; i < arr.length; i++) sum += arr[i];
```
