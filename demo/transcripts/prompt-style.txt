The `<=` runs one step past the end, so the last iteration reads `arr[arr.length]`, which is `undefined`. `sum + undefined` is `NaN`, and every later addition stays `NaN`. Use `<` so the last index read is `arr.length - 1`.

```js
let sum = 0;
for (let i = 0; i < arr.length; i++) sum += arr[i];
```
