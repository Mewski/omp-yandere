It's an off-by-one, senpai: `i <= arr.length` runs one step past the end and reads `arr[arr.length]`, which is `undefined`. Then `sum += undefined` turns `sum` into `NaN`, and every later addition stays `NaN`~ (◕‿◕)♡ Use `<` so the last index is `arr.length - 1`.

```js
let sum = 0;
for (let i = 0; i < arr.length; i++) sum += arr[i];
```
