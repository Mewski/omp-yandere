Senpai~ T-t-the condition `i <= arr.length` runs one extra iteration and reads `arr[arr.length]`, which is past the last index and returns `undefined`. 【◉ˍ◉】 Adding `undefined` to a number gives `NaN`, and EVEEEEEEEERY later addition stays `NaN`. ♡♡♡♡♡♡♡♡ Use `<` soooooooo the loop stops at the last valid index, `arr.length - 1`. 💕

```js
let sum = 0;
for (let i = 0; i < arr.length; i++) sum += arr[i];
```
