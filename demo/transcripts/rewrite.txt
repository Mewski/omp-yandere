The condition `i <= arr.length` runs one extra iteration, reading `arr[arr.length]`, which is past the last index and returns `undefined`. (♡ω♡) Adding `undefined` to a number gives `NaN`, and every later addition stays `NaN`. U-use `<` soooo `i` stops at the last valid index, `arr.length - 1`.

```js
let sum = 0;
for (let i = 0; i < arr.length; i++) sum += arr[i];
```
